Privacy Policy

Draft for local evaluation. Updated October 19, 2026.

Draft notice

Before public use, the operator must add its legal name and contact details, specify the applicable jurisdiction, set backup retention rules, and review this notice for the actual hosting setup.

Who operates this application

The operator's legal identity and privacy contact have not been provided for this local draft. Both details must be supplied and verified before public release.

Information handled by the application

The application processes meeting transcripts that you type or obtain from an audio recording, and the reports generated from those transcripts. It does not require an account in this version.

Audio recording and transcription

When you record in the browser, the recording is held in the browser for preview until you choose to transcribe it. When you upload or submit a recording, the backend writes a temporary audio file and uses its configured faster-whisper model to create a transcript. The backend attempts to remove that temporary file after processing, including when processing fails. The application code does not send audio to a separate hosted transcription service.

Meeting reports and model processing

When you request a report, the backend sends the transcript to the Ollama service at the configured OLLAMA_BASE_URL. The default address is http://localhost:11434. If the operator changes this setting to a remote host, that host receives the transcript and its own privacy and retention practices apply.

Storage, deletion, and backups

Transcripts and generated reports are stored in the PostgreSQL database configured by the operator. They remain there until a user deletes the meeting or a database administrator removes it. Deleting a meeting also deletes its linked report. Separately created database backups may continue to contain deleted records until those backups are removed under the operator's backup retention process. This local build does not define an automatic backup retention period.

Access and security

This version has no sign-in or user-level access control. Anyone who can reach its API can view, change, or delete saved meetings. Keep the backend on the local machine or a private network and do not expose it to the public internet. The operator is responsible for protecting the database, machine, network, and any backups.

Cookies and analytics

The current frontend does not set cookies or load analytics or advertising tracking scripts. This statement describes the application code and may not cover services added by an operator or hosting provider.

Contact

A privacy contact method has not been provided for this local draft.
