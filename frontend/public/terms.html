Operator and contact

The operator's legal identity and contact method have not been provided for this local draft. Add and verify these details before public release.

Use of the application

Use the application only with transcripts and recordings that you are permitted to process. You are responsible for informing meeting participants and obtaining any permissions required for recording, transcription, storage, and report generation.

Review generated content

Transcripts and AI-generated reports can contain recognition errors, omissions, or incorrect interpretations. Check the transcript and report against the recording before sharing them or relying on them for decisions or follow-up work.

Local access and data

This build has no sign-in or user-level access control. Keep it on the local machine or a private network. You are responsible for protecting the device, database credentials, network access, and backups. Meeting deletion removes the database record and linked report; separate backups are managed independently.

Model service configuration

Report generation sends transcript text to the Ollama service configured by the operator. The default is a service on the same machine. If a different host is configured, review that host's terms and data practices before sending meeting information to it.

Availability and changes

This is a local evaluation version. No uptime or support commitments are defined. Features and model behavior may change. The operator must add any service-specific commitments and jurisdiction-specific terms before public use.
